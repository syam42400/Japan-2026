Comment créer ce jeton ?
  1. Sur github.com : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access : sélectionne uniquement ce dépôt
  3. Permissions → Contents : Read and write
  4. Donne-lui une date d'expiration (par ex. juste après ton retour)
  5. Copie le jeton généré et colle-le ci-dessus

Il reste uniquement sur ce téléphone (stockage local du navigateur) et sert seulement à parler directement à GitHub — aucun autre serveur n'est impliqué.
